This repository marks the beginning of my journey into Git and GitHub. I'm learning how to manage source code, track changes, create commits, and build good development habits.

## 💻 Getting Started

Clone this repository to your local machine:

```bash
git clone <your-repository-url>
cd git_test
```

Start tracking your changes:

```bash
git status
git add .
git commit -m "Update project files"
git push
```

Replace `<your-repository-url>` with your actual GitHub repository URL.
